# Xilin Dai

An English research homepage for Xilin Dai, Ph.D. student at The Chinese University of Hong Kong.

## Preview

Run `python3 -m http.server 8080 --bind 127.0.0.1` in this directory and open `http://127.0.0.1:8080`.

## GitHub Pages

Upload this directory's contents to the root of a GitHub Pages repository. In the repository's **Settings → Pages**, choose **Deploy from a branch**, select the publishing branch, and use its root directory. The included `.nojekyll` file enables direct static publishing. All local asset paths work for both a user site and a project site.

## Content

Edit `index.html` for biography, education, publications, research experience, and service. The stylesheet is `assets/style.css`; publication filtering, navigation, and theme selection are in `assets/site.js`.
